# AIDos

一個簡單的瀏覽器插件（Manifest V3），可設定網站原始語言，並將網頁文字翻譯為繁體中文，效果類似沉浸式翻譯的基礎版本。

## 功能
- 點擊插件按鈕後，依選擇的網站語言將目前頁面翻譯為繁體中文（使用 Google 翻譯服務）
- 網站語言支援中文、英文、日文、韓文、西班牙文、義大利文、阿拉伯文
- 限制同時送出的翻譯請求並快取翻譯結果，避免大量請求造成服務節流與重複等待
- 會記住上次選擇的網站語言
- 可一鍵還原為原始文字

## 檔案結構
- `manifest.json`：擴充套件設定
- `background.js`：呼叫 Google 翻譯 API
- `content.js`：掃描與替換頁面文字
- `popup.html` / `popup.js`：操作介面

## 使用方式
1. 打開 Chrome，進入 `chrome://extensions/`
2. 開啟「開發人員模式」
3. 點「載入未封裝項目」並選擇此專案資料夾
4. 開啟網頁後，點插件圖示並選擇「網站語言」（翻譯目標固定為繁體中文）
5. 按「翻譯目前頁面」開始翻譯
6. 若要回復原文，按「還原原文」

## 注意
- 使用的是 Google 翻譯公開服務端點，可能受流量與可用性限制
- 動態載入的新內容不會自動翻譯，需再次點擊翻譯
